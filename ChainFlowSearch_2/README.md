# ChainFlow Search 2 🔍

**ChainFlow Search** は、爆速の初動と、思考を止めないインテリジェンスな絞り込みを両立させた、プロフェッショナル向けファイル検索エンジンです。

### 🆕 v2 での変更点
- **クエリマッチングの高速化**: `search_engine.py`の`is_match()`が、ファイル1件ごとにクエリの各語を再度Unicode正規化(NFKC)していた無駄を解消。正規化・否定(`-`)判定・ワイルドカード判定は`parse_query()`側で検索開始時に1回だけ計算し、以降はその結果を使い回す方式に変更。大量ファイルに対する複数語クエリで実測 約2倍以上高速化(20万件・8語クエリで150ms→67ms)。挙動(マッチ結果)はv1と完全互換。
- **検索中クローズ時のクラッシュ修正**: 検索(ディレクトリ列挙)が完了する前にタブを閉じる/アプリを終了すると、実行中の`QThread`がガベージコレクトされて異常終了する不具合を修正。タブ閉鎖時・ウィンドウ終了時に該当タブのワーカースレッドを確実に停止・待機してから破棄するように変更(`SearchWidget.stop_workers()`, `SearchWindow.closeEvent()`)。
- **多重起動の衝突を分離**: v1(`ChainFlowSearch`)と同じシングルインスタンス用サーバー名を使っていたため、v1とv2を同時に起動すると片方がもう片方に処理を委譲してしまう問題を修正(`ChainFlowSearch_Instance` → `ChainFlowSearch2_Instance`)。
- **結果ツリーをModel/View化**: `QTreeWidget`+`QTreeWidgetItem`(絞り込みのたびに全マッチ件数分のウィジェットを作り直す方式)を廃止し、`SearchResultModel`(`QAbstractTableModel`)+`SearchFilterProxyModel`(`QSortFilterProxyModel`)+`QTreeView`構成に刷新(新設: `search_results.py`)。スキャン結果は1回だけモデルに保持し、クエリ変更は`proxy.invalidateFilter()`のみで反映されるため、絞り込みコストが「マッチ件数」ではなく「画面に見えている行数」で決まるようになった。マッチ件数が数万件でも絞り込み時の再描画コストは一定。ソート・右クリックメニュー・ダブルクリックで開く・Ctrl+Cコピー・外部ドラッグ&ドロップは全てモデル/インデックス経由に書き換え、挙動はv1と同一。
- **検索を切り替えた際のUIフリーズを解消**: 検索実行中に別のクエリ(ワイルドカードの切り替えなど、ハイブリッド絞り込みの対象外になるケース)を入力すると、古いスキャン用スレッドを`.wait()`で同期的に待つ実装だったため、単一フォルダに大量のファイルが直に入っているようなケースでUIスレッド全体が数百ms〜それ以上フリーズしていた(実測: 15万件のフラットなフォルダで約364ms)。`SearchWidget._retire_worker()`を新設し、古いワーカーは`.wait()`せず「シグナルを切り離した上でバックグラウンドで自然停止するまで放置(GC対策として参照だけ保持)」する方式に変更。UIスレッドのブロック時間は約30ms前後まで縮小(実測)。タブ/ウィンドウを閉じる際は`stop_workers()`側で全ての退役中ワーカーも含めて確実に待機するため、以前修正したクラッシュ耐性は維持したまま。

### ✨ 主な機能 / Key Features
- **Hybrid Engine**: `os.scandir` を活用した超高速な「非同期スキャン」と、確定した結果に対する瞬時な「メモリ内ストリームフィルタリング」を統合。
- **Advanced Query Syntax**: Space (AND), `|` (OR), `-` (NOT), `*` (Wildcard) を組み合わせた、正規表現に迫る高度なクエリ発行が可能。
- **Multi-Tab Interface**: 異なるディレクトリや条件を複数のタブで並行して検索。タブの複製やパスの引き継ぎもサポート。
- **Smart History**: ディレクトリの訪問履歴を自動追跡。Filerのお気に入りとも連動し、よく使う場所へ即座に移動。
- **External Drag & Drop**: 検索結果をエクスプローラーや他のアプリケーションへ直接ドラッグ、あるいはコピー(`Ctrl+C`)して連携。

### 🛠️ 技術情報 / Technical Info
- **Framework**: PySide6
- **Architecture**: 双方向通信シグナルを用いた完全非同期ワーカースレッド。
- **Optimization**: バッチ通信によるUIへの段階的反映で、数万件のヒット時も操作性を維持。

### ⌨️ 操作方法 / Shortcuts
- `Ctrl + T`: 新しい検索タブ
- `Enter`: ファイルを開く / `Ctrl + C`: ファイルをコピー
- `Ctrl + F`: 入力エリアへフォーカス
- `Tab`: タブ間の移動
- `/`: クエリのクリア
